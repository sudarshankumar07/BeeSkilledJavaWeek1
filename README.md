# BeeSkilled Java Practice - Week 1

This repository contains my Java solutions for the Week 1 practice problems from the BeeSkilled Java program.

## Problems Solved

### Q1: Even or Odd Number

* Check whether a given number is even or odd using bitwise operators.

### Q2: Sum of Array Elements

* Calculate the sum of all elements present in an array.

### Q3: Reverse a String

* Reverse a string using Java's `StringBuilder`.

### Q4: Swap Two Numbers Without Third Variable

* Swap two numbers using:

  * Arithmetic operations
  * Bitwise XOR operator

### Q5: Multiplication Table

* Generate the multiplication table of a given number from 1 to 10.
